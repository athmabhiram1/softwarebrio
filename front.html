01 / THE PIPELINE

Five stages.
No magic.

A fixed, deterministic pipeline — no agent loops, no recursive crawling, no surprises. Each stage is a small module with one job and a typed boundary.

03 / DECISION LOG

Opinionated, on purpose.

fetchingD—01

httpx first, browser on evidence

Plain HTTP with a browser UA is tried first. The headless browser escalates only when cleaned text is thin (<500 chars) or the server answers 403 / 429 / 5xx — never on raw page size, since JS shells are large but empty.

extractionD—02

One LLM call per domain

Strict json_schema emitted from the Pydantic v2 model, one validation retry feeding ValidationError.errors() back, then a partial record. No per-page calls, no agent loops, no more than two requests ever.

scoringD—03

Confidence you can audit

Small chat models are miscalibrated — fluency is not evidence. The score is computed in Python from four observable signals: field coverage, page success rate, contact quality, and text quality. Failures land at 0.05.

resilienceD—04

Failures don't propagate

Timeouts, bot blockers and bogus domains are caught per-URL and per-domain. One dead site yields a low-confidence record with an errors array — the batch continues, and the process still exits 0.

04 / HONEST LIMITATIONS

Deliberate non-goals,
not oversights.

no-self-grade

No LLM-rated confidence. A deterministic formula replaces it, because small models can't reliably grade their own output.

no-founder-search

No LinkedIn / Tavily lookup. Deferred to the bonus phase — homepage leadership names are often customer quotes and need external verification to avoid misattribution.

no-agent-loop

No LangGraph / Browser-Use. A fixed httpx-first pipeline is deterministic, cheaper, and demoable in two minutes where an agent loop would add flake.

no-fake-pins

No fake Python pin in Docker. The Playwright base image ships 3.12; the code is written 3.11-compatible and the difference is documented, not hidden.

no-optimism

No assumption that plain HTTP always works. Hydrated subpages (vapi.ai-style) escalate to Playwright by design and are logged as such.

no-creep

Bonus seams stay seams. A search-fallback stub and a cost hook exist as marked NOT-BUILT interfaces — never called in the core path.

architecture

Six modules,
one direction of dependency.

config → models → fetcher → cleaner → extractor → main. Each module imports the last, owns one concern, and never hardcodes another's constants. No framework, no graph runtime — just typed boundaries.

02 / MODULE MAP

Small files.
Sharp edges.

/config.py

Env-driven constants

Every knob lives here — timeouts, thresholds, regex, model names. No magic numbers anywhere else in the codebase.

exports — FETCH_TIMEOUT_S=10 · ESCALATE_MIN_CLEAN_CHARS=500 · TOKEN_BUDGET=8000 · SUBPAGE_RE · MAX_SUBPAGES=5
/models.py

Two-model split

ExtractionPayload for the LLM (strict, no confidence field) and CompanyRecord for output, which adds the computed score and an errors list.

exports — ExtractionPayload · CompanyRecord · RunSummary · model_json_schema()
/fetcher.py

Conditional escalation

httpx AsyncClient first; a single shared Playwright browser launched only when cleaned text is thin or status says "blocked". Per-URL method logged.

exports — fetch_domain() → [{url, method, status, html}]
/cleaner.py

Text under budget

trafilatura precision pass, recall retry, then a BeautifulSoup decompose/get_text fallback. Concatenated longest-first under the 8,000-token cap.

exports — clean_page() → {text, path, raw_len, clean_len} · concat_domain()
/extractor.py

One call, one retry

Strict json_schema from the Pydantic model, a single retry feeding validation errors back, deterministic confidence in Python — the LLM never self-grades.

exports — extract_domain() · compute_confidence()
/main.py

Sequential orchestration

Domains processed in input order so the [{i}/{n}] cost lines print deterministically — one bad domain never stops the others, exit code stays 0.

exports — CLI --domains · live cost print · output.json writer

fetcher.py · config.SUBPAGE_RE

Resolve targets

The homepage is queued, then same-origin links matching the subpage regex are capped at five. Depth-1 only — no recursion, no external links, no crawling rabbit holes.

# config.py SUBPAGE_RE = r"/about|team|company|contact|pricing|leadership" MAX_SUBPAGES = 5 # depth-1, same-origin only
fetcher.py · httpx

Fetch — httpx first

Every page is tried over plain HTTP with a browser User-Agent and a 10-second timeout. Each result logs its URL, method, and status — the cheapest path is the default path.

async with httpx.AsyncClient(headers=UA, timeout=10.0) as client: r = await client.get(url) # → {url, method: "httpx", status, html}
fetcher.py · playwright

Escalate — on evidence

After cleaning, thin text (<500 chars) or a 403 / 429 / 5xx triggers a Playwright render. Raw HTML size is deliberately ignored — JS shells are huge and empty. One browser launches per run and is reused everywhere.

if len(cleaned) < ESCALATE_MIN_CLEAN_CHARS or status in {403, 429, 500+}: html = await render(page, url) # shared browser, context.close() first
cleaner.py · trafilatura → bs4

Clean & budget

trafilatura with favor_precision, a favor_recall retry, then a BeautifulSoup decompose fallback for script / style / nav / footer. Pages are concatenated longest-first and hard-truncated at the token budget.

text, path = clean_page(html) # trafilatura | recall | bs4 prompt = concat_domain(pages, budget=8000) # raw KB → clean KB logged
extractor.py · groq / ollama

Extract — one call

A single OpenAI-compatible request with a strict json_schema emitted from the Pydantic model. If validation fails, errors are fed back exactly once; after that, a partial record ships with its problems listed.

response_format={"type": "json_schema", "strict": true, "json_schema": {"name": "ExtractionPayload", "schema": emitted}} # max 2 calls ever · errors[] fed back on retry 1
extractor.py + main.py

Score & emit

Confidence is computed in Python from four observable signals — never self-reported by the model. The live cost line prints, totals reconcile against the summary, and output.json is written. Exit code 0, even on partial failure.

conf = round(min(1.0, max(0.0, .45*F + .25*P + .20*C + .10*Q)), 2) # [2/3] supabase.com: httpx×5 pw×1 │ … │ $0.00017 │ conf 0.96 │ 9.1s

05 / TROUBLESHOOTING

The three traps, pre-solved.

  • Ollama inside Docker can't connect

    Compose maps host.docker.internal:host-gateway and overrides OLLAMA_BASE_URL for you — on Docker Desktop it's a no-op, on Linux Engine it's the fix.

  • Groq rejects the json_schema with 400

    The schema emitter walks every object and sets additionalProperties:false plus complete required at every nesting level — verified with a live 200 against openai/gpt-oss-20b before shipping.

  • Playwright version mismatch on launch

    requirements pins playwright==1.62.0, exactly matching the v1.62.0-noble base image. If you bump one, bump both.
