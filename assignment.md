3. Technical Assignment: Autonomous Lead Enrichment Agent
Objective
Build a Python-based autonomous agent or pipeline that takes target company domains as input, crawls and parses their public web presence, and outputs structured intelligence using an LLM.
Input
Your script should accept an array/list of company domains. For testing, run your solution on these 3 targets:

postman.com
supabase.com
vapi.ai


Core Requirements
Step 1: Automated Browsing & Content Retrieval
Fetch the homepage and discover relevant subpages (e.g., /about, /team, /company, /contact, /pricing).
Handle dynamic, JavaScript-rendered content cleanly using headless browser automation (e.g., Playwright, Puppeteer, or Selenium).
Step 2: Context Pre-Processing & Token Optimization
Do not feed entire raw HTML trees into an LLM.
Extract clean markdown, text nodes, or specific DOM elements (strip out CSS, SVGs, scripts, and navigation boilerplate) to save LLM tokens and reduce latency.
Step 3: LLM Extraction (Structured Outputs)
Use an LLM of your choice (OpenAI, Anthropic, or open-source models via Groq, Together AI, or Ollama).
Use strict structured outputs (e.g., Pydantic, Instructor, or JSON Schema tool calling) to extract:
Company Overview: A concise 2-sentence summary of what they do.
Target Audience / ICP: Who their product is built for (e.g., "Developers building backend applications").
Contact Points: Any generic or public emails found on the site (e.g., contact@, sales@, support@).
Key Leadership / Team Members: Names, roles/titles, and LinkedIn profile URLs (if discoverable from the page content).
Data Confidence Score: An estimated score between 0.0 and 1.0 indicating the quality/completeness of the extracted data.
Step 4: Fallback & Resilience
Handle common web issues gracefully: 404 pages, bot blockers, timeouts, and missing elements. The script must never crash midway when one site fails.


4. Bonus Points (Optional, but gives you an edge)
Google/Search Integration: Having the agent use a search engine (like SerpAPI, Tavily, or custom browser search) to look up external LinkedIn URLs for founders if not found on the direct website.
Agentic Frameworks: Implementing dynamic navigation using tools like Browser-Use, LangGraph, or custom multi-step tool-calling loops.
Cost Tracking: Logging the number of tokens used and the estimated API cost per scraped domain.
